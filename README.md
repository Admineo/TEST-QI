# TEST-QI — quiz mobile de divertissement

Une expérience smartphone à fond bleu : 30 questions en 30 minutes, avec tirage aléatoire sans doublon depuis une banque locale de 150 questions, trois niveaux de jeu, trois domaines, son désactivable, résultats par domaine, correction expliquée, partage et sauvegarde/téléchargement. Le prénom et la tranche d’âge sont facultatifs. Aucune donnée n’est envoyée à un serveur. Le don PayPal est facultatif.

## Important : le score n’est pas un QI

Le résultat est uniquement le nombre de bonnes réponses à ce quiz. Il ne calcule et n’estime pas un QI. Ce contenu n’est pas standardisé, n’a pas de normes de référence, n’a pas fait l’objet d’une validation clinique et ne doit pas servir au diagnostic ou à la décision médicale. Un usage professionnel nécessite un instrument validé, autorisé et administré conformément à ses règles par un professionnel qualifié.

## Android

Télécharger le code source en ZIP : https://github.com/Admineo/TEST-QI/archive/refs/heads/main.zip

Pour installer le quiz web comme une application sur Android et activer le mode hors ligne, publiez d’abord le site sur un hébergement HTTPS. Ouvrez ensuite son adresse dans Chrome Android et sélectionnez « Installer l’application » ou « Ajouter à l’écran d’accueil ». Le ZIP est le code source, pas un APK.
