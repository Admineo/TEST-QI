# TEST-QI — quiz smartphone

Quiz récréatif mobile-first, avec fond bleu et interface tactile pensée pour Android et les petits écrans.

## Inclus

- 30 questions par partie et un minuteur de 30 minutes.
- Réserve de 150 questions, avec tirage aléatoire sans doublon : 10 questions par domaine (logique, calcul mental et observation visuelle).
- Trois niveaux de jeu : découverte, intermédiaire et expert.
- Prénom/pseudo et tranche d’âge facultatifs. Aucune donnée personnelle n’est envoyée ; le prénom n’est utilisé que pour l’écran de résultat et l’âge n’influence pas la note. Le sexe/genre n’est pas demandé.
- Score de jeu sur 30, résultat par domaine, partage, téléchargement texte, sauvegarde locale et correction expliquée.
- Son désactivable, service worker et installation web sur smartphone après publication HTTPS.
- Soutien facultatif via le lien PayPal.Me configuré dans l’application.

## Limite importante

Ce quiz est un jeu et ne mesure pas le QI. Il n’est pas standardisé, ne comporte pas de normes validées et ne permet pas de produire un score de QI, même présenté comme « non officiel ». Une évaluation de QI nécessite un outil psychométrique validé, adapté à l’âge et administré/interprété par un professionnel qualifié.

## Essai et téléchargement

Télécharger le code source en ZIP : https://github.com/Admineo/TEST-QI/archive/refs/heads/main.zip

Le ZIP contient le code du site ; ce n’est pas un APK Android. Pour installer le quiz web comme une application sur le téléphone, il faut d’abord publier le site sur une adresse HTTPS, puis l’ouvrir dans Chrome Android et choisir « Installer l’application » ou « Ajouter à l’écran d’accueil ».
